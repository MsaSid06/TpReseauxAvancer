# TpReseauxAvancer

## Mode d'emploi

Ce dépôt regroupe les rapports des travaux pratiques de Services Réseaux Avancés, rédigés au format Markdown.

### Consulter les rapports

Depuis la page principale du dépôt, cliquer sur le rapport souhaité pour afficher son contenu directement sur GitHub.

- [Rapport SSH](Rapport-SSH.md) : mise en place et utilisation du protocole SSH.
- [Rapport RDP](Rapport-RDP.md) : configuration et accès à distance via RDP.
- [Rapport VNC / NoVNC](Rapport-vnc-novnc.md) : configuration et utilisation de VNC et NoVNC.

### Structure du dépôt

```text
TpReseauxAvancer/
├── captures/              # Captures d'écran des TP
├── Rapport-SSH.md         # Rapport sur SSH
├── Rapport-RDP.md         # Rapport sur RDP
├── Rapport-vnc-novnc.md   # Rapport sur VNC et NoVNC
└── README.md              # Guide du dépôt
```

Les captures sont intégrées directement dans les rapports Markdown. Pour consulter un rapport avec ses illustrations, ouvrir simplement le fichier `.md` correspondant sur GitHub.
